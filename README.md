# Aetherward

Auto-battler / crystal defense roguelike 2D (Unity 6000.4.8f1) cho Windows, Android, iOS. Tối đa 6 hero quanh một Crystal, 6 nguyên tố, 15 phản ứng, 20 wave, draft/shop/relic/tiến hoá.

Trạng thái và hướng dẫn chi tiết: xem `Docs/` (bắt đầu từ `Docs/ENVIRONMENT_AUDIT.md`, `Docs/DECISIONS.md`).

## Kiểm thử ngoài Unity
```
cd Tools/SimHarness
dotnet test Tests            # EditMode tests (NUnit) chạy trên lớp mô phỏng pure C#
```
